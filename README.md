# Savourly

Food Recipe Explorer is a React Based Web Application design to provide users a simple and
interactive platform for exploring wide range of food varieties.

The application allows users to explore food varieties across different cuisines, in each
cuisine food is broadly divided into Non-vegetarian, Vegetarian as well as meal categories
such as breakfast, lunch and dinner.
User can view information about Recipe details, including cooking instructions, ingredients
and cooking time etc.

The project focuses on implementing key React.js concepts, including reusable components,
props, state management, routing, form handling, validation, and conditional rendering. It
also uses local storage to maintain user-specific data such as favourites, saved recipes, and
user-added recipes.
